## 三、排错速查

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 后端起不来 / XML 解析报错 | XML 里直接写了 `<` | 写成 `&lt;=`（模块8 第 1 节坑 1） |
| 关键词不生效、返回全部 | `or` 那组没加括号 | 见模块8 第 1 节坑 2，把 `or` 整组包起来 |
| 500 / `data` 是 null | Mapper 方法名和 XML 的 `id` 对不上 | 两边必须一字不差 |
| 改了没反应 | 后端没重启 | 重启 |
| `categoryName` 是 null | 没 join category，或列名没起别名 | 写 `c.name as category_name` |
| 停售的菜也返回了 | `status = 1` 漏了、或写进了 `<if>` 里 | 它要写死，不包 `<if>` |
| 报 `UnsupportedOperationException: 课 2 空②/③ 还没填` | 空没填 | 正常，回去填 |
| 空串关键词返回全部 | 只判了 `null` 没判 `''` | 判两个（模块8 第 1 节坑 3） |
