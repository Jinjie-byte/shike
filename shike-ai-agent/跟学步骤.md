## 一、这一课结束时你会看到什么

```
我问：剁椒鱼头多少钱？
它答：剁椒鱼头 的价格是 66.00 元。
```

以及**更重要的一条**：

```
我问：你们有波士顿龙虾吗？
它答：菜单里没有「波士顿龙虾」这道菜。
```

**第二条才是验收标准。** 它能证明"工具真的生效了" —— 一个**没有**接工具的模型，一定会一本正经地编一个龙虾出来。

## 二、为什么这一课用假数据

`app/tools.py` 里的 `FAKE_MENU` 是写死的假菜单，**课 2 才会换成真调 Java**。

为什么这么安排？因为这样你**一眼就能分辨**：

- 它答出 `66.00` → 说明它**真的读了你给它的数据**
- 它答得天花乱坠 → 说明它在**自己编**

如果一上来就接真数据库，你分不清"这个菜名是查来的还是编的"。**一次只加一个变量。**

### ★ 开工前先激活 venv（每次开新终端都要做一次）

**你机器上装了不止一个 Python。** 不激活的话，`python` 会跑到别的解释器上，
表现就是"**包明明装了，检查却说未装**" —— 这是最容易白费半小时的坑。

```bash
# CMD（推荐，最省事）
.venv\Scripts\activate.bat

# Git Bash
source .venv/Scripts/activate

# PowerShell（若报"禁止运行脚本"，先执行一次：
#   Set-ExecutionPolicy -Scope CurrentUser RemoteSigned）
.venv\Scripts\Activate.ps1
```

**激活成功的标志**：命令行提示符前面多出一个 `(.venv)`：

```
(.venv) D:\javatext\...\shike-ai-agent>
```

之后 `python step1_check.py` 就落在正确的环境上了。

**不想激活也行** —— 每条命令写全路径，效果完全一样：

```bash
.venv/Scripts/python.exe step1_check.py
```

> ⚠️ 它只对**当前这个终端窗口**生效。关掉窗口或新开一个，要重新激活。
> 忘了的话，`step1_check.py` 的第 `[0]` 行会直接告诉你用错了哪个解释器。

### [ ] 步骤 2 · 让模型学会"调工具"（本课核心）

**文件**：`step3_tool_demo.py`（填 **3 个空**）

**这一空最值得琢磨**：`空①` 是给工具写 **docstring**。

> 那段文字**不是写给人看的，是写给模型看的**。
> 模型靠它判断：什么时候该用这个工具、参数该怎么填。
> 写糊了有两个后果：模型压根不调它；或者调了但参数乱填。

```bash
.venv/Scripts/python.exe step3_tool_demo.py
```

**期望**：
- 第一问（剁椒鱼头）→ 答出 `66.00`
- 第二问（波士顿龙虾）→ 明确说"没有"，**不是编一个出来**

**如果第二问它编了龙虾**，说明你的 `SYSTEM_PROMPT` 或 docstring 还不够狠，回去改。

### [ ] 步骤 3 · 做成正式结构，暴露成 HTTP 接口

```bash

  -H "Content-Type: application/json" \
  -d '{"messages":[{"role":"user","content":"想吃辣的，30块以内"}]}'
```

**期望**：返回 `{"reply": "..."}`，里面的推荐**必须来自你的假菜单**。

## 六、排错速查

| 现象 | 原因 | 怎么办 |
|---|---|---|
| `ModuleNotFoundError: No module named 'xxx'` | 用了系统的 python，不是 venv 里的 | 先激活 venv，或改用全路径 `.venv/Scripts/python.exe` |
| **包明明装了，检查却说"未装"** | 同上 —— 检查时用的解释器不是 venv | 看 `step1_check.py` 第 `[0]` 行打印的解释器路径 |
| `401` / `AuthenticationError` | Key 没读到或写错 | 跑 `step1_check.py` 看第 3 项 |
| `Model Not Exist` / 400 | 模型名写了文档里没有的名字 | 用 `deepseek-flash`，见教材 3.4 |
| `Insufficient Balance` | 余额不足 | platform.deepseek.com 充值 |
| 模型答得很流畅但**没有调工具** | docstring 写太糊 / 没传 prompt | 把"什么时候用"写进 docstring，并在 SYSTEM_PROMPT 里加"必须先查再答" |
| 每次都答得不一样 | 没设 `temperature=0` | 加上 |
| `NotImplementedError: 空② 还没填` | 空没填完 | 正常，说明还没填 |

### 各文件干什么

| 文件 | 一句话职责 |
|---|---|
| `config.py` | 集中放"可变的东西"：Java 的地址、内部接口密钥。**不写死在代码里** |
